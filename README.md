# Amazon Homepage Clone

## Overview

This project is a front-end clone of the Amazon India homepage, built as a practice project to strengthen my HTML and CSS skills. The primary objective was to recreate the layout and styling of the original website while gaining hands-on experience with modern CSS concepts and page structuring.

> **Note:** This project is created solely for educational purposes and is not affiliated with or endorsed by Amazon.

---

## Features

* Hero banner section
* Product grid layout
* Multi-section footer
* Hover effects for interactive elements
* Clean and structured HTML & CSS

---

## Technologies Used

* HTML5
* CSS3
* Font Awesome (Icons)

## Learning Outcomes

Through this project, I gained practical experience with:

* Semantic HTML
* CSS Flexbox
* Box Model
* Positioning
* Hover effects and transitions
* Page layout design
* Website deployment using GitHub Pages
* Version control using Git and GitHub

---

## Limitations

* This project is currently optimized primarily for desktop screens.
* It is intended for learning purposes only and does not replicate Amazon's functionality.
* No backend functionality or JavaScript has been implemented.
